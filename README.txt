STORE INVENTORY SOH APP

START:
1. Extract SOH_Inventory_App.zip.
2. Open index.html in Chrome or Edge.
3. Search by style, barcode, colour, or size.
4. Use Upload SOH to load a newer Excel/CSV stock file.
5. Use Add Sold to record a sale and deduct stock.

NOTES:
- The initial inventory is embedded from the supplied 1510.xlsx (8,808 product rows).
- Stock edits and sales are saved in this browser's local storage.
- The app is browser-local; it does not automatically sync across devices.
- Excel import and camera barcode scanning use online libraries, so those features need an internet connection.
- Camera scanning generally requires HTTPS or localhost and camera permission.
- To publish online, host index.html and optionally set up a backend for shared/live data.
